# Review packet: Who Pays the Tariffs?

Thank you for reviewing. This packet is for a trade economist and should take about 30 minutes;
the questions are the most useful part to answer.

Report: <https://johnpospisil.github.io/tariff-pass-through/> (data through August 2026; tariff
legal status checked 2026-10-29). Code, data and tests:
<https://github.com/johnpospisil/tariff-pass-through>.

| File | What it is |
|---|---|
| [summary.md](summary.md) | One page: question, design, main estimates, caveats |
| [questions.md](questions.md) | Ten specific questions, most important first |
| [key_estimates.md](key_estimates.md) | Border, retail and diversion estimates with their specifications (generated) |
| [tariff_timeline.md](tariff_timeline.md) | The 34 tariff action groups with Federal Register / proclamation citations (generated) |
| [data_gaps.md](data_gaps.md) | Known data gaps and how each is handled |
| [validation.md](validation.md) | Pre-publication QA: reconciliation gates, recomputed numbers, issues found |

Regenerate the two generated files with `make review`. Full documentation of every source,
vintage and decision: [DATA.md](../../DATA.md).
